# Polite, cached fetcher for federalreserve.gov.
# Every page is stored in cache/ (body as .html, final URL after redirects as
# .url). A page already in cache is never requested again. Requests are spaced
# at least one second apart, and a 429 answer is retried after a wait.

library(httr2)

UA <- "AEM 6850 class demo; <address>"
CACHE_DIR <- "cache"
dir.create(CACHE_DIR, showWarnings = FALSE)

.last_request <- new.env()
.last_request$t <- 0

cache_key <- function(url) {
  key <- sub("^https?://", "", url)
  key <- gsub("[^A-Za-z0-9._-]", "_", key)
  file.path(CACHE_DIR, key)
}

# Returns list(html = <character>, url = <final url>)
fetch <- function(url, max_tries = 6) {
  key <- cache_key(url)
  html_file <- paste0(key, ".html")
  url_file <- paste0(key, ".url")
  if (file.exists(html_file) && file.exists(url_file)) {
    return(list(html = readr::read_file(html_file),
                url = readLines(url_file, warn = FALSE)[1]))
  }

  for (try in seq_len(max_tries)) {
    wait <- 1 - (as.numeric(Sys.time()) - .last_request$t)
    if (wait > 0) Sys.sleep(wait)
    .last_request$t <- as.numeric(Sys.time())

    resp <- request(url) |>
      req_user_agent(UA) |>
      req

**Running it:** `Rscript R/collect_statements.R`. All requests go through `R/fetch.R`, which sends your user agent, waits at least a second between requests and caches each page in `cache/` with its final URL. A cached page is never requested again. The server returned 429 four times, and each request was retried and then succeeded. In total 191 pages were fetched once each (16 calendar pages and 175 statements), and later runs make no requests.

**Choices you may want to change:**
- **What counts as a statement:** a row is the link labelled "Statement" for a meeting or call on the calendar pages. That leaves out the Statement on Longer-Run Goals, implementation notes, and calls that had no statement linked (all of 2009's calls, for example).
- **`scheduled` is FALSE for 10 rows:** the conference calls in 2007, 2008 and 2010, the March 2020 emergency actions, and October 11, 2019. The 2019 one followed a notation vote rather than a call, and I counted it as unscheduled.
- **Some FALSE rows are mostly not rate decisions.** March 11, 2008 (the securities lending facility) and May 9, 2010 (swap lines) are about liquidity programs, but the Fed lists them as the statement for those calls. They're easy to drop if you want rate decisions only.
- **`date` is the release date shown on the statement page**, so it can be a day after the meeting or call itself. I didn't take it from the URL because one link is misnamed: the June 2007 statement sits at `monetary20070618a.htm` but was released June 28.
- **`text`** keeps the statement paragraphs, the voting and dissent lines, and the "In a related action, the Board…" discount-rate paragraphs from 2006–2008. It drops the page header, media contact, implementation-note pointer, FAQ boxes, bold section headings and lists of links to other central banks. The 2008 and 2010 coordinated releases had the most of that clutter, and I checked those by hand.
- **The 2026 statements are short (about 130 words)** because the Committee moved to a shorter format, not because text was lost.

`fetch_log.txt` is the log from the first run (fetches and 429s).
