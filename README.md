# AEM 6850 — Unconventional Data for Economists

Course site for AEM 6850 (Charles H. Dyson School of Applied
Economics and Management, Cornell University), taught by
[Ariel Ortiz-Bobea](https://arielortizbobea.github.io/).

**Live site: <https://arielortizbobea.github.io/aem6850/>**

- `fall-2026/` — the Fall 2026 offering: syllabus, schedule, session
  manuals, slides, live scripts, and assignment briefs. Offerings are
  archived by year; a past year's folder is never edited.
- Built with [Quarto](https://quarto.org). Each session's manual
  page, slide deck, and runnable R script render from one `.qmd`
  source, so they cannot drift apart.
- Produced with AI assistance, disclosed per the course's own policy;
  the instructor wrote and verified every claim.

Homework starters, solutions, and quiz banks are not in this
repository; students reach them through Canvas and GitHub Classroom.
